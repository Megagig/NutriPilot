# 👤 Super Admin - Quick Start

## ⚡ Create Admin in 30 Seconds

### Option 1: Default Credentials (Fastest)

```bash
cd backend
npm run seed:admin
```

**Login with:**
```
Email:    admin@nutripilot.com
Password: Admin@123456
```

---

### Option 2: Custom Credentials (Recommended)

```bash
cd backend
npm run create:admin
```

Follow the prompts to enter your own credentials.

---

## 🎯 What You Get

✅ Super Admin account  
✅ Email pre-verified  
✅ Admin role assigned  
✅ Ready to login immediately  

---

## 🚀 Next Steps

1. **Start backend** (if not running)
   ```bash
   npm run dev
   ```

2. **Open NutriPilot app**

3. **Sign in** with admin credentials

4. **Test authentication!**

**"MongoDB connection error"**
- Check if MongoDB is running
- Verify MONGO_URI in .env
